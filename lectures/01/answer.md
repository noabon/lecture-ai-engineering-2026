- 取り組んだレベル：基礎 / 実装
- やったこと：

- 結果：
■基礎
２つのモデルは説明の組み立て方と具体例の選び方が異なっていた。

3.5-flash-liteは従来手法の課題から入り、パラメータ数を数百億〜数兆、本体を数十GBと大きめの数値で示している。例えは「メモ帳を添える」の一つのみ。メリットには「元の性能が劣化しにくい」点を挙げ、活用例ではCivitaiやELYZAなどの固有名詞を出している。

一方の3.6-flashは、Microsoftの技術という出自に触れ、本体を数GBと一桁小さく示している。例えは「家のリフォームと付箋」の二つを使っている。メリットにはRTX 3060という具体的なGPU名や複数LoRAの混合利用を挙げ、活用例は画風や口調など用途別に回答していた。

最後にtemperatureで0.6を指定した場合の違い。
AIE_MODEL=3.5-flash-lite uv run python -m app.ask --temperature 0.6 "LoRAとは何ですか？"

temperature変更した文章は、仕組みを3つの手順に分けて示し、学習対象が元モデルの1%〜0.1%程度に減るという具体的な数値を加えています。また、背景でGPTやStable Diffusionを名指しし、パラメータ数を「数百億〜数千億」としている。また、メリットの記載や無料クラウドで数分〜数時間で学習できるという記述もなくなった。活用例でも、Civitaiの代わりに「現在最も主流の手法」という位置づけを示し、LLMの例はELYZAに替えてMistralを挙げている。まとめは、3.5-flash-liteが「研究や個人開発を加速させた立役者」としているのに対し、追加の文章は「省エネ学習技術」としている。

■実装
app/ask.py に対話モードを追加した。

uv run python -m app.ask --interactive
uv run python -m app.ask --interactive "LoRAとは何ですか？"

会話を終了する場合には、「終了」と入力する。
